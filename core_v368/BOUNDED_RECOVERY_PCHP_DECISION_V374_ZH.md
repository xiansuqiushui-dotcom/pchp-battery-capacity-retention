# 有界恢复 PCHP 开发决策（V374）

执行日期：2026-08-02  
预冻结协议：`BOUNDED_RECOVERY_PCHP_PREFREEZE_V374_ZH.md`、`BOUNDED_RECOVERY_PCHP_PREFREEZE_V374.json`  
最终决策：`REJECT`  
主稿动作：不修改 V368 权威方法、摘要、标题、外部确认或主要结果。

## 1. 冻结问题

本轮检验严格非增 PCHP 的一个电池相关替代解释：允许每条已发布记录最多上升 \(\rho\)，是否能够在保持前缀因果、逐记录损害预算、物理范围和递归可行性的同时，稳定改善跨域效用。全部 \(12\) 个域历史上均已打开，因此该检验从一开始就限定为协议锁定的回顾性开发证据，而不是新的外部确认。

## 2. 实现与理论检查

有界恢复算子满足预期实现契约：

- \(\rho=0\) 时与 V321 严格 PCHP 逐元素完全一致；
- 最大绝对位移和最大观测绝对损失增量均为 \(0.010000000000000009\)，在 \(10^{-12}\) 容差内满足 \(\delta=0.01\)；
- 受保护状态和输出的最大恢复上限超额均为 \(4.34\times10^{-18}\)；
- 前缀重放最大差为 \(0\)；
- \(6/6\) 项性质测试通过。

因此，失败不是代码、递归可行性或确定性证书失败，而是跨域经验效用没有达到预冻结强度。

## 3. 主结果

源域内层选择在全部 \(12\) 个外层域均选择了网格最大值 \(\rho=0.005\)。外层域等权电芯宏平均 MAE 从严格 PCHP 的 \(0.07038\) 降至 \(0.06958\)，有界恢复减严格 PCHP 的配对差为

\[
-0.00079,
\]

域聚类 bootstrap \(95\%\) 区间为

\[
[-0.00273,\ 0.00103].
\]

域胜/平/负为 \(7/0/5\)。改善出现在 CALB、HNEI、MATR、MICH\_EXP、SDU、UL\_PUR 和 XJTU；CALCE、HUST、MICH、RWTH 和 SNL 变差。最差域电芯宏平均 MAE 从严格方法的 \(0.14531\) 上升至 \(0.14974\)。

主效应区间和改善域数量两项中央门失败，故按预冻结停止规则判定 `REJECT`。

## 5. 科学解释与禁止动作

结果表明，有限正向恢复在部分域可能有用，但现有数据不支持它作为跨域稳定改进替换严格 PCHP。全部内层选择均落在 \(\rho\) 网格上界，还意味着当前公开开发域可能继续偏好更松的轨迹；按照预冻结规则，不允许在同一批结果上扩大网格或重设门槛进行救援。只有未来存在由工程采样间隔定义且未参与本轮选择的新数据时，才可以重新提出独立的恢复计划。

本轮禁止：

1. 把点估计改善写成方法升级成功；
2. 删除五个变差域或改用记录等权估计目标；
3. 扩大 \(\rho\) 网格后在同一数据上重新宣称确认；
4. 把逐记录恢复上限解释为电化学恢复率；
5. 改写 BaSyTec 或 NASA 的冻结结论。

当前权威结论仍是严格非增 PCHP；V374 只作为负证据台账保留。
