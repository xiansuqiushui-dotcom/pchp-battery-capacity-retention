# BaSyTec 解析开发样本预声明 V347

记录时间：2026-08-02 07:16:23（Asia/Shanghai）

在任何 `Ah[Ah]` 数值被读取之前，永久指定字典序首个电芯 `F0001` 为解析开发样本。该电芯及其所有循环不得进入后续外部确认的点估计、置信区间、门槛判断、图表或成功率统计。

允许从 `F0001` 获得的信息仅用于：

1. 确定 BaSyTec 累计电量列的符号、复位方式以及如何机械恢复每循环放电容量；
2. 验证循环、时间、电流、电压、温度与容量字段之间的行级对齐；
3. 构造不含科学结论的解析单元测试。

禁止用 `F0001`：

1. 选择或修改源模型；
2. 选择特征窗口、锚点数、名义容量、投影区间、
   PCHP 的 \(\alpha\) 或 \(\delta\)；
3. 选择比较器、聚合单位、置信区间方法或通过门槛；
4. 依据预测误差、改进方向或安全门槛表现调整任何科学规则。

确认样本预先固定为官方名单中除 `F0001.zip` 外的其余 (47) 个电芯。只有在新的解析器、测试、确认协议及其 SHA-256 全部冻结后，才允许读取这 (47) 个电芯的容量数值。
