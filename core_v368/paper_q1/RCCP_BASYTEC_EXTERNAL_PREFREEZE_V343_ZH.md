# PCHP BaSyTec 外部确认预冻结协议（V343）

## 1. 冻结目的

本协议在下载或读取 Zenodo 记录 `10.5281/zenodo.15755725` 的任何数据文件之前冻结。它检验已经完成开发的前缀因果损害预算投影（PCHP）能否在新的 BaSyTec 电芯老化域中，同时满足以下两项要求：

1. 相对于同一受保护因果基线获得跨电芯平均效用；
2. 保留逐记录精确损害预算、输出范围与非增轨迹证书。

本次验证还冻结一个更强的无保护运行比较器，用于定量展示安全约束的精度机会成本。该比较器的结果必须报告，但不被用作事后修改 PCHP 的依据。

## 2. 外部数据身份

- 数据集：*Degradation path indicators for lithium-ion batteries*；
- Zenodo DOI：`10.5281/zenodo.15755725`，版本 (1)；
- 关联论文 DOI：`10.1016/j.est.2025.119113`；
- 许可：CC BY 4.0；
- 电芯：Varta CP1654 商业石墨/NMC 电芯；
- 冻结标称容量：(0.124,mathrm{Ah})；
- 设计：(48) 个物理电芯、(24) 种温度—倍率组合、每个电芯 (70) 个老化循环；
- 文件规则：纳入官方记录中的全部 (48) 个 `Fxxxx.zip`，每个压缩包必须且只能包含一个 `M0002_aging.txt`。

冻结前的工作区语义与文件名搜索没有发现该 DOI、数据集标题、`M0002_aging` 或 `extracted_degradation_metrics` 的既有副本。该结果只证明当前项目目录未检测到既有暴露，不能替代作者团队的历史确认。

因此，证据标签按以下规则确定：

- 如果团队此前看过结果，则降级为“回顾性外部验证”；
- 无论哪种情况，都不能称为新的实验室前瞻试验。

## 3. 两阶段信息隔离

### 3.1 标签盲预测阶段

预测程序只允许访问：

- 循环身份；
- 充电侧时间、电流、电压；
- 存在时的充电侧温度。

程序可以为结构核验读取放电容量列的列名，但不得读取该列的任何数值。预测程序必须先写出并哈希冻结：

- 全部结构合格的特征行；
- 原始受保护预测；
- 原始学习候选；
- 受保护因果基线；
- PCHP 输出；
- 源域调参的无保护因果候选。

### 3.2 容量解封与评分阶段

只有标签盲预测报告和预测文件均已写出并通过 SHA-256 核验后，独立评分程序才能读取：

- 冻结循环身份；
- 电流符号；
- 冻结的 `Ah-Cyc-Discharge` 容量字段。

评分程序不得重算特征、重新拟合模型、改变参数或覆盖预测。

## 4. 冻结输入和特征契约

对每个循环，取第一个能够通过既有特征契约的连续正电流片段。电流活动阈值固定为 (10^{-5},mathrm{A})，早期充电窗口固定为 (600,mathrm{s})。特征包括充电量、电压、电流与温度统计量，以及 (0) 至 (600,mathrm{s}) 的冻结插值点，不因该数据的分布而增加或删减。

前五个结构合格循环只用于建立投运参照；第六个及以后循环生成预测。若真实文件的字段不能被预冻结别名唯一识别，则对应电芯失败关闭，不允许在数据访问后增加新别名。

源模型固定为：

- `rccp_source_model_freeze_v316/rccp_source_models_v316.joblib`；
- PCHP 同化率 (alpha=0.01)；
- 损害预算 (delta=0.01)；
- 输出范围 ([0,1.3])。

强无保护比较器使用同一冻结学习候选，并按

\[
q_1=\Pi_{[0,1.3]}(c_1),\qquad
q_t=\Pi_{[0,1.3]}\!\left[q_{t-1}+0.05\min(c_t-q_{t-1},0)\right]
\]

递归更新。其 (alpha=0.05) 来自十二个开发域一致的源域嵌套选择，不使用本外部数据标签。

## 5. 标签契约

同一循环容量定义为负电流记录中 `Ah-Cyc-Discharge` 字段的最大有限正绝对值。每个电芯的参照容量为前五个结构合格循环容量的中位数：

\[
Q_{i,\mathrm{ref}}
=\operatorname{median}(Q_{i1},\ldots,Q_{i5}),
\qquad
y_{it}=\frac{Q_{it}}{Q_{i,\mathrm{ref}}}.
\]

参照容量必须位于 ([0.08,0.16],mathrm{Ah})。若前五个循环中的任一容量无效，排除完整电芯，不得用更晚循环替代。锚点后的个别无效容量只排除相应记录并计数，不改变冻结预测。

每个确认性电芯至少需要 (10) 条可评分锚点后记录；总执行资格至少需要 (36) 个物理电芯。

## 6. 统计设计

独立分析单位为物理电芯，循环是电芯内重复测量。先在每个电芯内计算全部可评分锚点后循环的 MAE，再对电芯等权平均。主要估计量为

\[
\widehat{\Delta}
=\frac{1}{C}\sum_{i=1}^{C}
\left[
\frac{1}{T_i}\sum_{t=1}^{T_i}|p_{it}-y_{it}|
-
\frac{1}{T_i}\sum_{t=1}^{T_i}|b_{it}-y_{it}|
\right].
\]

使用物理电芯为重采样单位、随机种子 (20{,}260{,}808) 的 (100{,}000) 次 percentile bootstrap 报告 (95\%) 区间。排除平局后的双侧精确符号检验只作描述性补充。

## 7. 冻结判定门槛

执行资格：至少 (36) 个物理电芯满足标签契约，否则结果为 `INCONCLUSIVE`。

只有以下条件全部通过，结果才为 `RETAIN`：

1. (widehat{\Delta}<0)；
2. 排除平局后，至少三分之二的电芯改善；
3. 电芯 bootstrap 区间的上端点小于 (0)；
4. 最大逐记录位移、最大观察绝对损失增量和最大电芯宏平均 MAE 损害均不超过 (delta=0.01)，容差为 (10^{-12})。

执行资格成立但任一门槛失败时，结果为 `REJECT`。强无保护比较器的精度及其损害管违反情况无论结果方向如何均须报告，但不改变上述 PCHP 判定规则。

## 8. 停止规则

从本协议落盘起，不得根据真实数据修改：字段别名、标称容量、时间窗、锚点数量、文件或电芯纳入规则、源模型、(alpha)、(delta)、输出范围、统计单位、聚合方式、bootstrap 方案或通过门槛。失败结果必须保留。
