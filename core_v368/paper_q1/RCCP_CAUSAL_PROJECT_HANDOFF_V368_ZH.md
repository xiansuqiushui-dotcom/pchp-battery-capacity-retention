## 3. 方法主脊柱与原创性边界

PCHP 的不可替代主张不是一般投影、三角不等式或单调回归，而是以下组件形成的单一在线契约：

1. 冻结源域预测产生不访问未来记录的前缀因果、非增受保护状态；
2. 损害预算、SOH 物理范围与已发布轨迹共同形成精确在线可行核：每个核内当前输出对任意未来非增受保护状态路径均可延拓，核外点已违反当前契约；
3. 学习候选被投影为该核内与候选距离最小的唯一输出；
4. 对所有允许结果，逐记录相对损害均受声明预算控制；
5. 执行只使用当前及过去信息，已发布历史不可被未来观测改写；
6. 在固定输出契约下，完整双预测器因果级联对前缀 $\ell_\infty$ 范数非扩张，且常数 $1$ 为紧常数。

去除 PCHP 名称、流程图与电池包装后，精确结果一致损害域、前缀不变执行、递归非增可行性和唯一候选保真决策仍然成立，因此“去包装创新”审计结论为 `PASS`。

V370 进一步把共形校准“不伤害”效率、保守上下文赌博机和反事实不伤害控制纳入最近邻比较。它们分别保护预测分布、累积策略损失或策略造成的约束违反；本稿保护的是结果揭示前逐点预测损失和不可回写轨迹。有限检索支持 `SCOPED_GAP_IDENTIFIED`，不支持普遍“首次”。

V371 把外部确认标准纠正为设计独立性：确认结果不能影响方法、已拟合预测器、超参数、估计目标、排除规则或判定门，评分预测须在结果访问前固定。数据公开、既往采集或单实验室来源会限制外推范围，但不会自动取消确认属性。论文同时明确部分充电可得、参考容量延迟、跨供应商或协议偏移、长期趋势与不可回写记录如何实质决定方法设计，避免被误读为通用机器学习后处理。

V372 进一步统一标题、摘要、Highlights、投稿信和图文摘要的编辑第一印象：从“部分充电记录先到、参考容量标签后到”的真实电池信息失配切入，把核心创新集中为递归可行的在线预测契约，并统一使用“结果盲、协议锁定的外部确认”。确认资格只取决于结果揭示前方案已冻结且确认结果没有反向改写设计，不再要求整个团队或项目谱系从未接触数据，也不再以继续堆叠数据集作为默认门槛。

V373 正面处理“只是简单裁剪”的原创性风险：正文证明当前约束交集不仅是必要充分最大集合，也是所声明输出契约的精确在线可行核，并把 PCHP 写成该核内唯一最近候选解。相关工作主动纳入预测安全过滤器这一强结构最近邻，明确区分被修改对象、保护对象、不确定性来源和成立条件；有限检索仍只支持 `SCOPED_GAP_IDENTIFIED`。本轮没有增加数据、调整模型或扩大经验主张。

V374 以预冻结方式检验“允许每条记录有限正向恢复”能否替换严格非增契约。虽然点估计略有改善且全部确定性证书通过，但域 bootstrap 区间跨过零，且仅 \(7/12\) 个域改善，未达到冻结的 \(8/12\) 门槛，因此结论为 `REJECT`。不得扩大恢复网格、改变估计目标或删除失败域进行救援；严格非增 PCHP 仍是权威方法。

V375 不增加方法模块，也不继续堆叠数据集，而是检验主要效用是否依赖 ExtraTrees 特定误差结构。在 Ridge、HistGradientBoosting 和 LightGBM 上直接复用主骨干的逐外层域 \(\alpha\) 日程，不允许骨干特异性调参；三个骨干的 PCHP 减受保护状态域等权 MAE 差均约为 \(-0.0042\)，Bonferroni 调整后的 \(98.33\%\) 区间均低于零，且全部确定性证书通过。该结果排除了三个所审计模型族内的 ExtraTrees 特异性解释，但不支持普适模型独立、深度模型可移植或最佳骨干优越性。由于全部开发域此前已打开，V375 属于回顾性开发稳健性证据，而不是新的外部确认。

V376 将外部确认边界固定为设计独立性，并把保守在线凸优化、逐阶段保守线性赌博机和未知约束在线学习纳入直接最近邻审计。本文不再把团队或项目谱系的绝对隔离当作必要条件，也不再以继续增加数据集作为默认改进路线。

V377 没有增加数据集或经验主张，而是证明完整 PCHP 级联在固定契约下具有前缀 $\ell_\infty$ 非扩张性。最近邻审计主动纳入移动时域单调趋势滤波和单调游走滤波，明确不主张“首次提出稳定单调滤波器”；本文更窄的增量是冻结双预测器、移动损害管与不可回写输出前缀组成的完整级联稳定性。局部近端形式只解释 $\alpha$ 的当前保真度—状态惯性作用，不是统计或电化学最优性主张。

V378 不增加数据集、不改外部确认，也不重新训练。它针对开发阶段只有 \(12\) 个完整数据域这一有限样本事实，穷举每项比较的全部 \(2^{12}=4{,}096\) 个配对符号分配，并补充 Student-\(t\)、精确 Wilcoxon 与方向符号检验。主效应和积分预算路径的负向均值保持稳健；候选无关比较支持域等权平均效用，但只在 \(9/12\) 个域获胜，方向符号检验值为 \(0.145996\)。因此不得把该结果写成普适支配或“随机新域改善概率大于一半”。

## 5. 当前可支持的主要主张

### 5.1 理论与实现

- 对任意度量损失，精确结果一致损害等于候选与受保护输出之间的度量距离；
- 在有界结果区间上的平方损失具有依赖受保护状态位置的非对称精确可行域；
- 当结果遍历整个实数轴时，任何非平凡平方损失更新的最坏相对损害均无有限上界；
- 当前约束交集是对任意未来非增受保护状态路径均可延拓的精确在线可行核，区间投影是其中唯一最近候选解；
- 受保护状态更新具有精确局部近端形式；完整因果级联在固定契约下满足前缀 $\ell_\infty$ 非扩张界，常数 $1$ 为紧常数；
- 冻结数值审计覆盖 \(200{,}000\) 个有界平方损失配置及 \(256{,}000\) 次在线递归执行，全部通过；历史 PCHP 单元测试 \(30/30\) 与独立 V377 扩展测试 \(4/4\) 均通过，损失几何验证 \(27/27\) 具名检查通过；V377 验证器还通过 \(3{,}888\) 项受保护状态局部检查、\(21{,}168\) 项投影局部检查、\(108\) 项近端等价检查和 \(30{,}000\) 对随机轨迹检查。
- V378 对开发主效应、候选无关控制和积分预算路径分别穷举 \(4{,}096\) 个域级符号分配；三项 Student-\(t\) 区间上界与三项符号翻转结果均保持负向域等权平均结论，同时明确保留候选控制 \(9/12\) 个域获胜这一异质性边界。

这些结果证明公式—代码一致性与在线契约，不证明电池基线准确、普遍方法优先权或真实运行成本合理。

### 5.2 经验结果

- 开发证据：\(12\) 个公开域、\(586\) 个电芯、\(601{,}932\) 条记录；域等权电芯宏平均 MAE 从 \(0.07524\) 降至 \(0.07038\)，域聚类 \(95\%\) 区间为 \([-0.00671,-0.00301]\)，\(12\) 个域中 \(11\) 个改善；
- 候选信息控制：相对于源域选择的候选无关预算可行偏移，PCHP 的 MAE 进一步降低 \(0.00477\)；
- 跨骨干可移植性：Ridge、HistGradientBoosting 和 LightGBM 的配对差分别为 \(-0.00419\)、\(-0.00425\) 和 \(-0.00422\)，Bonferroni 调整后的 \(98.33\%\) 区间分别为 \([-0.00677,-0.00131]\)、\([-0.00633,-0.00203]\) 和 \([-0.00621,-0.00231]\)，逐域胜/平/负为 \(10/0/2\)、\(11/0/1\) 和 \(11/0/1\)；
- 负结果边界：有界恢复 V374 的配对差为 \(-0.00079\)，\(95\%\) 区间为 \([-0.00273,0.00103]\)，仅 \(7/12\) 个域改善，因此按冻结规则拒绝；
- 机会成本：无保护因果比较器达到 MAE \(0.05470\)，但在全部 \(12\) 个域、\(586\) 个电芯和 \(524{,}165\) 条评分记录上违反 \(\delta=0.01\) 的损害预算；
- BaSyTec 前瞻锁定外部验证：\(45/45\) 个合格电芯改善，配对差为 \(-0.00986\)，电芯 bootstrap \(95\%\) 区间为 \([-0.01000,-0.00959]\)；事后固定 \(+0.01\) 略优 \(0.00014\)，因此不支持“自适应普遍优于固定校正”；
- NASA 压力测试：相对效用与确定性损害控制保留，但暴露冻结目标定义与部分电池绝对 SOH 标签不兼容。
