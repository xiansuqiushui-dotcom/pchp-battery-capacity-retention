# PCHP V364 统计证据审计

审计日期：2026-08-02  
审计对象：`rccp_causal_manuscript_v364/main_en.tex` 与 `main_zh.tex`  
判定：新增预算路径证据的独立单位、主要估计量、重采样层级和解释边界一致；V361 唯一失败项为展示层精度导致的操作性假阴性，已由独立冻结的 V362 审计闭合。

## 1. 新增分析的统计契约

- 分析性质：协议锁定的回顾性机制敏感性分析；开发域结果此前已经打开，不是外部确认。
- 独立单位：完整数据域，共 $12$ 个；电芯和记录均为域内嵌套测量。
- 冻结预算网格：

  $$
  \delta\in\{0,0.0025,0.005,0.0075,0.01,0.015,0.02,0.03\}.
  $$

- 主要逐域估计量：

  $$
  A_d=\frac{1}{0.03}\int_0^{0.03}
  \left[\operatorname{MAE}^{\mathrm{PCHP}}_d(\delta)-
  \operatorname{MAE}^{\mathrm{shift}}_d(\delta)\right],\mathrm d\delta.
  $$

- 数值积分：冻结网格上的梯形法。
- 汇总：$12$ 个 $A_d$ 的域等权均值。
- 不确定性：固定随机种子 $20{,}260{,}811$，对完整数据域执行 $100{,}000$ 次百分位 bootstrap。
- 多重性边界：积分 AUC 是唯一主要估计量；逐预算区间只是同一路径的描述性切片，不作为七项独立确认检验。

## 2. 比较器公平性

对每个外层数据域、预算和候选 $\alpha$，候选无关比较器只使用其余十一个源域。常数偏移由内层域等权电芯宏平均绝对误差的精确加权中位数给出，再截断到 $[-\delta,\delta]$；随后仍只用源域选择 $\alpha$。因此，比较器在声明约束内是源域最优的常数安全偏移，不使用外层目标标签，也不是人为选择的弱常数基线。

## 3. 主要复算结果

| 项目 | 结果 | 判定 |
|---|---:|---|
| 域等权预算归一化 AUC 差 | $-0.0069422305$ | 支持 PCHP |
| 域 bootstrap $95\%$ 区间 | $[-0.0110829091,-0.0029569290]$ | 上界低于 $0$ |
| 逐域胜/平/负 | $11/0/1$ | 与主要方向一致 |
| 七个正预算的域等权均值 | 全部低于 $0$ | 描述性一致 |
| $\delta=0.0025$ 差值 | $-0.0018863307$ | PCHP 更低 |
| $\delta=0.01$ 差值 | $-0.0047731285$ | 复现固定预算比较 |
| $\delta=0.03$ 差值 | $-0.0120468006$ | PCHP 更低 |

上述结果支持的结论仅为：在已打开的开发域中，记录特定候选信息的效用优势不局限于 $\delta=0.01$，也不能被每个预算下的精确源域最优常数偏移解释。它不证明该优势在新实验室普遍成立，也不标定实际工程预算。

## 4. V361 假阴性与 V362 独立审计

V361 的冻结总门槛要求历史锚点、结构门槛、AUC 均值、bootstrap 上界和多数正预算方向全部通过。实际运行中，除一个绝对 MAE 锚点外，其余门槛均通过，故原始报告按协议保留 `NARROW`。

失败原因是 V361 从 V327 报告 JSON 读取了十位小数展示值 $0.0703775121$，再以绝对容差 $10^{-12}$ 与当前高精度值比较。V327 权威 CSV 值为 $0.0703775121469438$，二者相差约 $4.69\times10^{-11}$。V362 在不重算科学结果、不修改 V361 文件、不改变容差的前提下，改用预先存在的高精度权威 CSV 并独立核验：

- 全部冻结输入哈希一致；
- 汇总 PCHP MAE、基线 MAE及其差值一致；
- $12$ 个域的 PCHP MAE 最大绝对差为 $9.71\times10^{-17}$；
- $12$ 个域的基线 MAE 最大绝对差为 $0$；
- V326 逐域 $\alpha$ 清单、内层分数和“未使用外层目标标签”全部一致；
- V361 的 AUC、bootstrap 区间及全部非锚点科学门槛未改变。

因此，该问题归类为已解决的 `P1 operational validation defect`，不是统计效应失败，也不是允许删除的历史记录。正文和补充材料均披露这一谱系。

## 5. 尚存统计边界

- 开发证据只有 $12$ 个完整数据域，区间主要刻画已观察域集合的异质性。
- MICH 与 MICH\_EXP 具有共同来源；既有来源组合并与逐组删除敏感性仍须保留。
- 预算路径在开发结果打开后才冻结，不能升级为确认性分析。
- 各预算点区间不可被解释为经过多重校正的独立显著性检验。
- 确定性逐记录损害证书不依赖重采样；经验效用仍依赖现有域集合。
- 没有真实维护或质保代价，故 $\delta$ 的运营含义仍未识别。

## 6. 最终判定

新增预算路径显著加强了“学习候选并非简单常数偏移”的机制防守，同时没有制造伪重复或多重确认主张。统计链条可接受，但证据等级必须保持为“协议锁定的回顾性开发敏感性分析”。
